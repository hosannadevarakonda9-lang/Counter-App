# Counter App 

A simple JavaScript Counter App built using HTML, CSS, and JavaScript.

##  Features
- Increment counter
- Decrement counter
- Reset counter
- Color change based on value
  - Green for positive
  - Red for negative
  - Black for zero

##  Technologies Used
- HTML
- CSS
- JavaScript
